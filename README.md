# shun-learning-log : エンタープライズDXへの40日間助走記録

## 🎯 目的
報道（記者/デスク/キャスター）11年、総務（IT人材育成/採用）、そして約4年間DX推進責任者としてBPRを牽引した15年間の経験を、エンタープライズ領域へスケールさせるための学習記録。
現場の痛みがわかる強みを活かし、地に足のついた業務改革とエンタープライズDXを推進し、一気通貫で成果にコミットする人材を目指す。

## 🗓️ 期間
